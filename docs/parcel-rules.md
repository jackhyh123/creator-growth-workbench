# 包裹状态与提醒判定规则

工作台的包裹视图把「走到哪」和「有没有问题」分成两层，避免一个下拉里混两种概念。

## 一、运输阶段（一级）

| 阶段 | 判定依据（任一命中） |
|---|---|
| 仓内待出库 | 后台状态为待支付／待付款；或原始状态含 待打包 / 待出库 / 仓内 |
| 国内待起飞 | 已出库 / 已揽收 / 等待航班 / 国内转运 |
| 国际运输中 | 已起飞 / 国际中转 / 未达目的国 |
| 海关处理中 | 含 海关 / 清关中 / 待缴税 |
| 清关后派送 | 已放行 / 已交当地邮政 / 正在派送 / 等待领取 |
| 已签收 | 已签收 / 已送达 / 已领取 / 妥投 |

待付款的包裹归入「仓内待出库」，所以按仓内待出库筛选时也会包含它们。

## 二、包裹状态（二级）

每个包裹只落在**一个**状态里，判定顺序自上而下：

| 顺序 | 状态 | 判定 |
|---|---|---|
| 1 | 待付款／补款 | 后台状态为待支付／待付款 |
| 2 | 运单号待补 | 没有运单号，且不是已签收/已取消 |
| 3 | 取消／退回 | 主体状态或子状态含 取消 / 退回 |
| 4 | 已过期 | 物流状态为过期 |
| 5 | 查不到轨迹 | 有单号但承运商查不到（Not Found / 未注册） |
| 6 | 异常 | 命中异常关键词或子状态为异常 |
| 7 | 状态待确认 | 判断不出阶段 |
| 8 | 已签收 | 已签收 / 妥投 |
| 9 | 正常 | 其余在途 |

## 三、提醒标签（可与状态并存，但不再重复状态已表达的信息）

| 标签 | 含义 |
|---|---|
| 物流异常 | 承运商明确报异常（扣留、退回、派送失败等） |
| 7 天无更新 · 待核查 | 最后一条轨迹距今 ≥ 7 天；已签收、已取消不触发 |
| 待缴税 | 等付税费 |
| 状态待核查 | 阶段判断不出 |

## 四、常见子状态映射

| 承运商原文 | 中文 |
|---|---|
| Exception_Security | 安检扣留 |
| Exception_Returning / Exception_Returned | 退回中 / 已退回 |
| Exception_NoBody | 派送无人接收 |
| Exception_DeliveryFailed | 派送失败 |
| Exception_Damaged | 破损 |
| DeliveryFailure_Other | 派送失败（其他） |

未收录的子状态统一显示为 `异常·原文`，避免出现英文原文。
